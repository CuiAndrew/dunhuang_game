# 敦煌逃亡（Dunhuang Run）

一款以敦煌壁画为视觉主题的浏览器 3D 跑酷原型。玩家沿着不断延伸的三车道路线前进，躲避障碍、收集铜钱，并在追兵逼近前尽可能跑得更远。

当前仓库根目录是原生 JavaScript ES Modules 应用：Three.js 通过 import map 从 CDN 加载，游戏页面由静态 HTTP 服务器提供；项目没有单独的打包步骤。`dunhuang_runner_vite_v10/` 是参考素材与实现，不是根项目的启动目录。

## 当前内容

- 三车道跑酷：换道、跳跃、滑铲、弯道和断层路线。
- 玩法循环：障碍碰撞、追兵距离、铜钱、磁铁/护盾/加速道具、分数与本地最高分。
- 敦煌主题：本地场景、人物动作、障碍、道具和 HUD 插画；图片加载失败时由程序化视觉兜底。
- 游戏界面：开始、暂停、继续、结算与重开；屏幕方向提示和键盘/触控操作。
- 音频反馈：Web Audio 合成环境音乐与游戏音效；浏览器不支持或限制音频时，游戏可静默降级。
- 长跑与性能：固定步长更新、复用轨道/障碍/拾取物/环境装饰，并按持续低帧率降低渲染质量。

## 本地运行

### 运行测试

需要安装 Node.js 和 npm。仓库中的 `three` 开发依赖供自动化测试使用：

```bash
npm install
npm test
```

### 启动游戏

从仓库根目录执行下面两步。根项目是静态原生 ES Modules 应用，正确的启动方式是 Python 静态服务器，不是 `npm run dev`：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

保持服务器终端运行，再在现代浏览器打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。按 `Ctrl+C` 停止服务器。不要直接双击 `index.html`，否则浏览器会以 `file://` 加载，import map 和模块资源可能无法正常工作。

已有浏览器标签页如果打开的是 [兼容入口 `index 2.html`](index%202.html)，该入口与 `index.html` 保持同步；新会话推荐使用根地址。

游戏运行需要支持 WebGL、原生 ES Modules 和 import maps 的浏览器。首次加载 Three.js 0.169.0 需要访问 unpkg CDN；请使用联网环境，并通过 HTTP 服务器访问，不要直接双击 `index.html`。游戏图片随仓库本地提供，图片加载失败时会回退到程序化绘制。

## 操作方式

| 操作 | 键盘 | 触控滑动 |
| --- | --- | --- |
| 左右换道 | `← / →` 或 `A / D` | 左右滑动 |
| 跳跃 | `空格 / ↑ / W` | 向上滑动 |
| 滑铲 | `↓ / S` | 向下滑动 |
| 暂停 / 继续 | `P / Esc` | 点击暂停 / 继续按钮 |

浏览器通常要求先有用户交互才允许播放 Web Audio；开始游戏后音乐和音效才会尝试启动。若浏览器策略、设备或系统设置阻止音频，会静默降级，不影响跑酷操作。

## 项目结构

```text
src/
├── main.js                 # 场景装配、状态接线与游戏循环
├── core/                   # 配置、输入、状态机、固定步长循环
├── entities/               # Runner、追兵与相机
├── world/                  # 轨道、环境、障碍和拾取物
├── systems/                # 碰撞、道具、计分与性能预算
├── art/                    # 主题注册、资源加载、材质与敦煌美术
├── audio/                  # Web Audio 音乐与音效
└── ui/                     # HUD、菜单、暂停与结算界面
tests/                      # Node.js 内置测试
```

关键入口：[`index.html`](index.html)、[`src/main.js`](src/main.js)、[`src/core/Input.js`](src/core/Input.js)、[`src/art/ThemeRegistry.js`](src/art/ThemeRegistry.js)。测试由 Node.js 内置 `node:test` 运行，不需要额外测试框架。

## 美术主题扩展

主题通过 [`src/art/ThemeRegistry.js`](src/art/ThemeRegistry.js) 注册，并遵循 [`src/art/ThemeDefinition.js`](src/art/ThemeDefinition.js) 的视觉工厂契约。主题负责色板、场景、人物和道具外观；轨道、碰撞类型、道具状态与计分逻辑不依赖具体主题。当前默认并已提供的主题是敦煌；上海外滩目前只是可沿同一接口扩展的方向，不是仓库中已交付的主题。

## 已知限制

- Three.js 从 CDN 加载，因此首次运行需要网络；当前没有离线打包版本。
- 画面依赖 WebGL；不支持 WebGL 的浏览器无法运行 3D 场景。
- 最高分和静音偏好保存在当前浏览器的本地存储中，不含账号同步、在线排行榜或服务端存档。
- Web Audio 受浏览器自动播放策略影响；音频不可用时仅静音运行。
- `npm test` 覆盖自动化逻辑与资源/界面契约；真实设备的帧率与移动端表现仍应在目标设备上体验确认。
