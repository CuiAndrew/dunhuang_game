## 可复现命令

```bash
npm test
python3 -m http.server 4173 --bind 127.0.0.1
```

浏览器验收重点：打开 `http://127.0.0.1:4173/`，点击“开始逃亡”，确认 HUD 距离增长；点击暂停确认覆盖层出现，再点击继续恢复；确认笔记本方向键 `←/→` 与屏幕左右方向一致。2026-09-20 冒烟记录：`MENU → PLAYING`，距离持续增长，`PLAYING → PAUSED → PLAYING`，重开后仍可进入 `PLAYING`，方向键左右无反向，控制台日志为空。
